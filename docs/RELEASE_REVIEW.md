# 1.2.0-rc.1 预发布说明

本候选版已经本地审阅，维护者已授权测试通过后发布至现有 GitHub 仓库。本次保留 `rc.1` 预发布标识，不将尚未完成的 Microsoft PowerPoint 实机交互检查表述为通过。构建、检查与打包命令本身不执行 GitHub 写入。

## 本次包含

- 24 个通用原生组件，保留获认可的暖白红橙玻璃风格。
- 汇报、演讲、培训、产品介绍各 6 页，共 24 页可编辑样例。
- 可复制的 PPTX、可复用输入文件、组件参数索引和可移植离线生成器。
- 原生数据图表、嵌入式工作簿、表格、分组与附着连接线。
- 新版组件输入与旧版 11 类简易版式兼容共存。

## 已完成的检查

从 ZIP 解包后独立安装，生成组件库和四类用途样例，共 48 页。自动回归测试、文件结构和布局检查、图表工作簿校验、逐页渲染审阅、LibreOffice 打开另存、离线生成、防覆盖与公开内容审计均通过。测试中修复了全零数据导致预览坐标无效、小数刻度被错误取整的问题，并加入回归测试。详细范围见[测试记录](TEST_REPORT.md)。

## 稳定版前仍需验证

在 Microsoft PowerPoint 中修改代表性文字、移动节点、编辑图表数据和表格，然后保存并重新打开。本机未安装该应用，本次没有执行这些交互检查。也未验证 Windows、Linux、Keynote 或 Google Slides。

字体未嵌入。透明渐变与阴影近似玻璃，不提供 CSS 实时背景模糊。HTML 设计预览、实际 PPTX 渲染、程序化编辑测试与 PowerPoint 实机交互测试是不同检查，不能相互替代。

原始银行材料、标识、业务数据、个人目录、凭据、依赖目录和本地提取素材不进入候选包。演示数字与产品概念均不是实际业务成果或上线承诺。
