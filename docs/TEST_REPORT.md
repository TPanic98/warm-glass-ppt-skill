## 本轮修复

- 全零数据：预览纵轴使用正的默认上限，避免出现无效坐标；指标柱形图不再输出零跨度纵轴。
- 小数刻度：HTML 预览保留有效小数，原生图表保留原数值及通用数字格式。

## 未覆盖和使用限制

- 本机没有 Microsoft PowerPoint，未执行改字、移动节点、编辑图表数据、增删表格行列及保存重开的实机交互检查。
- 未验证 Windows、Linux、Keynote、Google Slides，以及所有第三方字体组合。
- Microsoft YaHei 未嵌入。实际渲染采用可用字体回退；投屏与编辑设备需安装一致字体并复核换行。
- PPT 以透明渐变、细边和阴影近似玻璃材质，不提供 HTML 的实时背景模糊。两种导出不保证像素一致。
- 真实数据的事实准确性、出处权限和业务结论由使用者核实。示例数字、情境及产品能力均不代表实际业务成果。
